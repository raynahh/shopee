# Shopee Nusantara - E-Commerce Web & PWA

Aplikasi web e-commerce modern mirip Shopee yang responsif, interaktif, dan mendukung instalasi ke layar utama HP (Progressive Web App).

## Fitur Utama
- **Header Shopee**: Logo kustom, search bar dinamis dengan live suggestion, badge keranjang & notifikasi.
- **Banner Slider Promo**: Carousel promo otomatis dengan banner kampanye dan navigasi panah.
- **Pita 8 Layanan**: Gratis Ongkir XTRA, Shopee Mall, Pulsa & Tagihan, Murah Lebay, dll.
- **Grid 10 Kategori**: Ikon interaktif untuk memfilter produk secara langsung.
- **Flash Sale Kilat**: Live countdown timer real-time, badge diskon besar, dan progress bar stok terbakar.
- **Katalog Produk & Rekomendasi**: Sortir harga/diskon/terlaris, badge Mall/Star+, rating bintang, dan tag Terjual.
- **Quick View Modal**: Rincian produk, varian ukuran/warna, stepper kuantitas, dan jaminan originalitas.
- **Drawer Keranjang Belanja**: Pemilihan barang, kode voucher promo (ONGKIRNOL, SHOPEE50K), rincian kalkulasi subtotal, dan simulasi checkout COD/ShopeePay.
- **Dukungan PWA**: Tombol instalasi langsung ke beranda HP Android & iPhone tanpa membuka browser.

## Teknologi
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **PWA**: `vite-plugin-pwa` + Web App Manifest + Service Worker
- **Icons**: Lucide React

## Menjalankan Secara Lokal
```bash
# 1. Install dependensi
npm install

# 2. Jalankan dev server
npm run dev

# 3. Build untuk produksi
npm run build
```
